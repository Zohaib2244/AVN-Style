# UX

The rules for how AVN tools work, independent of any look. Agents start at [`SKILL.md`](SKILL.md).

- `references/*.md`: the rules, one topic per file (process, foundations, stack, shell, pages, components, pickers, data,
  rules-and-highlights, feedback, tools, assistant, motion).
- `assets/components.css`: every component as plain CSS using only contract roles.

How to change it: [`docs/CHANGING-THE-UX.md`](../docs/CHANGING-THE-UX.md). The live reference is [`board/index.html`](../board/index.html).
