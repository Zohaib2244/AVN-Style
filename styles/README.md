# Styles

Each folder is one look. A project picks one; the UX works with any.

| Folder | What |
|---|---|
| `avn-family/` | default; calm warm-dark, pixel icons, personal flavour (Nutmeg + 4 palettes) |
| `nutstyle/` | AVN Hub's chunky sticker look (8 palettes) |
| `_template/` | copy this to start a new one |

Files in a style: `SKILL.md` (what it looks like, for agents), `tokens.css` (required: fills the contract),
`fonts.css`, `skin.css`, `flavour.css` (optional). How to add one: [`docs/ADDING-A-STYLE.md`](../docs/ADDING-A-STYLE.md).
Check them all: `npm run check-styles`.
